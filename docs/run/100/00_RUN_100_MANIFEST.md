## Cycle contract

Every cycle must terminate with exactly one of:

1. a strict unconditional improvement of `0.95063832187565` (or of the newest
   floor once raised); or
2. a rigorous impossibility theorem for a precisely defined method class,

cycle.  Reviews, audits, and tests are restricted to one narrow integration
checkpoint per 90 minutes unless progress is otherwise impossible.  Finished
artifacts are uploaded immediately.
